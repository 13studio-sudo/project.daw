// PATCH · v0.2.0 The WaveShaper distortion curve was the source of an idle DC injection of ~−48 dBFS (visible in the Freq Matrix as lit cells at 20–100 Hz when nothing was playing). The 256-entry curve was sampled at (2i)/n - 1, which makes curve[127]=-0.0078 and curve[128]=0. WaveShaper interpolates at x=0 to the midpoint of those two, producing constant -0.0039 output for silent input — which the FX delay loop's 0.42 feedback then amplified. Fixed by sampling at (2i+1)/n - 1 so the curve is antisymmetric around the half-index midpoint: silence in → exact silence out.
// upgrade · v0.5.0 Freq matrix sizing rewritten in JS for pixel-perfect cell geometry. A ResizeObserver on the panel-body wrapper computes the largest integer cell-size that fits the available space, then writes it as a CSS variable used by the grid's grid-template-columns: repeat(N, var(--fm-cell)). Result: cells are always exactly square, gaps are always exactly 2px in both directions, and the matrix letterboxes inside the panel (Option A — never distorts). Works identically in 20×10 and 40×20 modes.
// upgrade · v0.4.0 Panels renumbered to sequential [00]–[07] with no gaps. Freq matrix now offers two resolutions via a dropdown in its panel head: 20×10 (200 cells) and 40×20 (800 cells). Both modes share a 2:1 container aspect-ratio, so switching doesn't reshape the panel. Each cell is locked to 1:1 via redundant CSS constraints (container aspect-ratio: COLS/ROWS + cell aspect-ratio: 1/1) so cells stay square at any panel size.
// upgrade · v0.3.0 Both ScriptProcessorNode uses (bitcrusher + WAV recorder tap) have been replaced with AudioWorkletNode processors. ScriptProcessor was deprecated and ran DSP on the main thread; AudioWorklet runs on the audio thread with lower latency and no jank risk. The bitcrusher exposes its bits and normFreq values as AudioParam descriptors so they're properly automatable, and the worklet node has accessor properties (.bits, .normFreq) that route writes through setValueAtTime — preserving the existing dispatcher syntax. Worklet sources are defined as JS string literals in the main file, Blob-wrapped, and loaded via audioWorklet.addModule(blobURL) so PROJECT-DAW stays a single HTML file.

[ 02 ] · workspace layout

// studio layout · 12-column fractional grid · 4px gap

Two layers. Layer 0 is the docked grid: panels snap into a computed grid-template-columns derived from each panel's fractional coords. Layer 1 is the overlay layer: the [00] let's play welcome panel floats freely above with z-index: 50 and backdrop-filter: blur.

[ 03 ] · theming system

// 5 source variables → ~30 derived tokens via color-mix()
tokenroledefault

Every other token in the system — --ink-faint, --ink-ghost, --panel, --hover, --active, etc. — is computed via color-mix(in srgb, …). Changing the 5 source tokens re-themes the entire app instantly.
